**Windows:** download `TTSReader-Setup-<version>.exe` and run it. It installs for your user, so there's no admin prompt. If SmartScreen warns, click *More info → Run anyway*. The portable zip is the same app unpacked: extract it anywhere and run `TTSReader.exe`.

**macOS (Apple Silicon, macOS 14+):** open the `.dmg` and drag **TTS Reader** into Applications. The app isn't notarised by Apple, so the first launch is blocked. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway** next to TTS Reader, and confirm.

Ignore the "Source code" downloads below. They're the Python files, not the app.
